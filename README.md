# 🌸 Iris Flower Classification using Neural Networks

## 📌 Overview
This project builds a **Neural Network model using TensorFlow/Keras** to classify iris flowers into three species based on their features.

It covers the complete workflow from data preprocessing to model evaluation.

---

## 🎯 Objective
To develop a machine learning model that can accurately classify iris flower species.

---

## 📂 Dataset
- Iris dataset  
- 150 samples  
- 4 features:
  - Sepal Length  
  - Sepal Width  
  - Petal Length  
  - Petal Width  
- 3 classes:
  - Setosa  
  - Versicolor  
  - Virginica  

---

## ⚙️ Tech Stack
- Python  
- TensorFlow / Keras  
- Scikit-learn  
- Pandas  
- NumPy  
- Matplotlib  

---

## 🧠 Model Architecture
- Input Layer (4 features)  
- Dense Layer (10 neurons, ReLU)  
- Dense Layer (8 neurons, ReLU)  
- Output Layer (3 neurons, Softmax)  

---

## 🔄 Workflow
1. Data Loading  
2. Data Preprocessing  
3. Train-Test Split  
4. Model Building  
5. Model Training  
6. Model Evaluation  
7. Visualization  

---

## 📊 Results
- Accuracy: ~90%+  
- Good performance on test data
